# Proyecto 1: LSA con SVD - Analisis Historia de Genshin Impact

Este repositorio contiene la implementación de un Análisis de Semántica Latente LSA utilizando la Descomposición en Valores Singulares (SVD) aplicada a un corpus de 50 documentos sobre la historia del videojuego Genshin Impact.

## Estructura principal del Proyecto:
- ``main.ipynb``: Jupyter Notebook principal con todo el preprocesamiento, analisis y visualizacion.
- ``archivos\``: Carpeta que contiene los 50 documentos (.txt) del corpus.
- ``requirements.txt``: Archivo de texto que contiene todos los nombres de las librerias necesarias para ejecutar ``main.ipynb`` correctamente.
- ``Informe.pdf``: Informe detallado con la metodologia y planteamiento de los resultados.

## Recomendaciones para el correcto ejecutamiento de ``main.ipynb``:
- Clonar el repositorio (si no lo quiere clonar, descargue la carpeta ``archivos``, ``requirements.txt`` y ``main.ipynb`` en un mismo directorio y en el mismo nivel)
- Ejecutar la primera celda de codigo de ``main.ipynb`` para descargar todas las librerias necesarias y despues ejecute cada celda en orden.
